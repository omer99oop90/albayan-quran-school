# مدرسة البيان لتعليم القرآن الكريم | Albayan Quran School System

نظام رقمي وتطبيقات ذكية متكاملة لإدارة حلقات تحفيظ القرآن الكريم والطلاب، مبني وفق أحدث تقنيات تطبيقات الويب الهجينة والأجهزة المحمولة بنظام **Offline-First**.

---

## 🌟 أبرز مميزات المنظومة

### 1. تطبيق الإدارة والمعلمين (`AlbayanApp.apk`)
- **إدارة الحلقات والطلاب**: إنشاء الحلقات، نقل الطلاب، وتعيين الكادر التعليمي.
- **رصد الحفظ والمراجعة وأوجه السرد**: جداول ذكية تفاعلية وسريعة الاستجابة لرصد درجات الحفظ الجديد (من 40)، المراجعة والتثبيت (من 30)، الحضور والانضباط (من 30 مع احتساب الخصومات آلياً)، ومواد العلوم المصاحبة والأنشطة (المجموع 200 درجة).
- **السيرة الذاتية القرآنية (`Student CV`)**: بطاقات شاملة ومفصلة لكل طالب توثق المسيرة القرآنية والمستوى والدرجات.
- **نظام الشهادات والأوسمة (`Certificates Engine`)**: مصمم شهادات تفاعلي يدعم تخصيص الخلفيات والخطوط وتصدير الشهادات بصيغ عالية الدقة.
- **إدارة الاختبارات والأسئلة**: إنشاء اختبارات قرآنية وتحديد الأسئلة الشفوية والتحريرية مع تصحيح ذكي.
- **لوحات تحليلات بيانية متقدمة (`Analytics Dashboard`)**: إحصائيات دقيقة حول نسب الإنجاز والمواظبة على مدار الأشهر الهجرية والمحصلة السنوية.

### 2. تطبيق بوابة الطلاب (`AlbayanStudent.apk`)
- واجهة مخصصة وسهلة الاستخدام للطلاب وأولياء الأمور.
- متابعة الحفظ اليومي، سجل العلامات، ونتائج الاختبارات فور رصدها.
- أمان محكم برمز سري رقمي خاص بكل طالب لحماية الخصوصية.

### 3. بنية تقنية بدون اتصال (`100% Offline-First Architecture`)
- قاعدة بيانات محلية ذكية مدمجة (`IndexedDB` + `Outbox Queue`).
- مزامنة سحابية ثنائية الاتجاه فورية ومستقرة مع **Firebase Realtime Database**.
- دعم كامل للأجهزة اللوحية وهواتف أندرويد عبر **Capacitor**.

### 4. هوية بصرية مريحة للعين بدون ظلال (`Zero-Shadow Design`)
- واجهة مستخدم فائقة الوضوح والسرعة خالية تماماً من الظلال (`box-shadow: none`).
- وضوح كامل عبر الحدود الأنيقة والألوان المتباينة.
- استجابة فورية فائقة السرعة للوحة المفاتيح وزر الحذف على مختلف أنواع الهواتف.

## 🚀 تشغيل بوابة تثبيت التطبيقات

المنظومة مزودة بمحرك خفيف ذاتي التشغيل على المنفذ `5000` لتحميل وتثبيت التطبيقات مباشرة:

```powershell
cd c:\now
npx -y serve static -p 5000
```
أو عبر النقر المزدوج على:
```cmd
open_server.bat
```
ثم فتح المتصفح على: `http://localhost:5000/`

---

## 🛠️ بناء حزم أندرويد (APK)

- لبناء تطبيق الإدارة:
```powershell
.\build_apk.ps1
```
- لبناء تطبيق الطلاب:
```powershell
.\build_student_apk.ps1
```

## 📂 هيكل المشروع الأساسي

```text
├── android/               # مشروع أندرويد الأصلي لتطبيق الإدارة (Capacitor)
├── student_app/           # كود وتطبيق بوابة الطلاب المستقل
│   ├── www/               # أصول واجهة تطبيق الطالب
│   └── android/           # مشروع أندرويد لتطبيق الطالب
├── static/                # بوابة تثبيت وتحميل التطبيقات
│   ├── downloads/         # حزم APK الجاهزة للتثبيت
│   └── index.html         # الصفحة الرئيسية للبوابة
├── .agents/skills/        # المعايير وقواعد العمل الذكية للمنظومة
├── build_apk.ps1          # سكريبت بناء تطبيق الإدارة الآلي
├── build_student_apk.ps1  # سكريبت بناء تطبيق الطلاب الآلي
└── open_server.bat        # مشغل البوابة السريع
```
